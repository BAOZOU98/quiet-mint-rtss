# 安装与还原

## 安装

1. 安装官方 RTSS 7.3.7。
2. 从 Releases 下载补丁包，**完整解压**后双击 `安装补丁.cmd`，在 Windows 弹出的提示中允许以管理员身份运行。
3. 安装时如果游戏正在运行，重新打开游戏后生效。

安装器会切换到静谧薄荷皮肤和简体中文，导入性能面板，并保留已有的 OSD 位置、帧率上限和开机启动设置。
部分游戏的配置文件可能覆盖全局显示设置。

## 缺少读数时

运行 `检查组件.cmd` 查看各项依赖的状态。

- 1% Low、RLAT、PCL 需要另外安装 NVIDIA FrameView SDK，并且游戏要提供相应数据；不少游戏在主菜单中没有 PCL。
- CPU / GPU 占用依赖本机传感器是否被 RTSS 支持。

## 还原

运行 `还原补丁.cmd`。

还原的目标是**第一次安装本补丁之前**的状态，其中可能已包含你自己的改动，并不等同于恢复出厂设置。
备份保存在 `%LOCALAPPDATA%\QuietMintRTSS\FullPatch`；重复安装不会覆盖第一次的备份。

## 其他说明

- 安装器需要管理员权限才能写入 RTSS 安装目录；它不会安装 NVIDIA SDK，也不会关闭游戏。
- 早期测试版附带过 `QuietMintPreview` 预览插件，现已撤回；升级时会先备份再移除它及其配置项。
